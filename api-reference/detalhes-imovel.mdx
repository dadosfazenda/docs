---
title: "Detalhes do Imovel"
api: "GET /imovel/{codigo_imovel}"
description: "Dados detalhados de um imovel rural: titulares, cartorio, CCIR e areas"
---

## Descricao

Retorna dados completos de um imovel rural a partir do seu codigo.
Use esta rota apos a [Busca por CPF/CNPJ](/api-reference/busca-por-cpf) para obter detalhes de um imovel especifico.

Os dados sao cacheados por 7 dias para evitar consultas repetidas.

<ParamField path="codigo_imovel" type="string" required>
  Codigo do imovel (retornado como `codigo_imovel` na rota de listagem).

  Exemplo: `433133781`
</ParamField>

## Response

<ResponseField name="message" type="string">
  Mensagem descritiva do resultado.
</ResponseField>

<ResponseField name="data" type="object">
  <Expandable title="data">
    <ResponseField name="codigo_imovel" type="string">
      Codigo do imovel.
    </ResponseField>

    <ResponseField name="denominacao" type="string">
      Nome do imovel (ex: `Fazenda Esperanca`).
    </ResponseField>

    <ResponseField name="municipio" type="string">
      Municipio sede do imovel.
    </ResponseField>

    <ResponseField name="uf" type="string">
      UF do imovel (ex: `GO`).
    </ResponseField>

    <ResponseField name="area_total_ha" type="number">
      Area total do imovel em hectares.
    </ResponseField>

    <ResponseField name="classificacao_fundiaria" type="string">
      Classificacao fundiaria (ex: `Grande Propriedade Produtiva`).
    </ResponseField>

    <ResponseField name="area_certificada" type="number">
      Area certificada em hectares.
    </ResponseField>

    <ResponseField name="area_registrada" type="number">
      Area total registrada em cartorio em hectares.
    </ResponseField>

    <ResponseField name="area_posse_justo_titulo" type="number">
      Area de posse por justo titulo em hectares.
    </ResponseField>

    <ResponseField name="area_posse_simples_ocupacao" type="number">
      Area de posse por simples ocupacao em hectares.
    </ResponseField>

    <ResponseField name="modulos_fiscais" type="number">
      Quantidade de modulos fiscais.
    </ResponseField>

    <ResponseField name="titulares" type="array">
      Lista de titulares do imovel.

      <Expandable title="titular">
        <ResponseField name="nome" type="string">
          Nome do titular.
        </ResponseField>
        <ResponseField name="cpf_cnpj" type="string">
          CPF ou CNPJ do titular.
        </ResponseField>
        <ResponseField name="condicao" type="string">
          Condicao de titularidade (ex: `Proprietario Ou Posseiro Individual`).
        </ResponseField>
        <ResponseField name="percentual" type="number">
          Percentual de detencao do imovel.
        </ResponseField>
      </Expandable>
    </ResponseField>

    <ResponseField name="areas_registradas" type="array">
      Dados de registro em cartorio do imovel.

      <Expandable title="area_registrada">
        <ResponseField name="area" type="number">
          Area registrada em hectares.
        </ResponseField>
        <ResponseField name="matricula" type="string">
          Matricula ou transcricao no cartorio.
        </ResponseField>
        <ResponseField name="livro_ou_ficha" type="string">
          Livro ou ficha do registro.
        </ResponseField>
        <ResponseField name="registro" type="string">
          Numero do registro.
        </ResponseField>
        <ResponseField name="data_registro" type="string">
          Data do registro.
        </ResponseField>
        <ResponseField name="cartorio" type="string">
          Nome do cartorio (CNS ou oficio).
        </ResponseField>
        <ResponseField name="municipio_cartorio" type="string">
          Municipio do cartorio.
        </ResponseField>
        <ResponseField name="uf_cartorio" type="string">
          UF do cartorio.
        </ResponseField>
      </Expandable>
    </ResponseField>

    <ResponseField name="ccir" type="string">
      Numero do CCIR (Certificado de Cadastro de Imovel Rural).
    </ResponseField>

    <ResponseField name="situacao_ccir" type="string">
      Situacao do CCIR (ex: `CCIR Quitado`).
    </ResponseField>

    <ResponseField name="data_vencimento_ccir" type="string">
      Data de vencimento do CCIR.
    </ResponseField>

    <ResponseField name="valor_ccir" type="number">
      Valor total do CCIR.
    </ResponseField>

    <ResponseField name="debitos_anteriores_ccir" type="number">
      Debitos anteriores do CCIR.
    </ResponseField>

    <ResponseField name="car" type="object">
      Dados do CAR vinculado. `null` se nenhum CAR foi encontrado.

      <Expandable title="car">
        <ResponseField name="codigo" type="string">
          Codigo do CAR (ex: `GO-5203401-617CD0C0367A49CD809862F382945511`).
        </ResponseField>

        <ResponseField name="municipio" type="string">
          Municipio do CAR.
        </ResponseField>

        <ResponseField name="estado" type="string">
          UF do CAR (ex: `GO`).
        </ResponseField>

        <ResponseField name="area_ha" type="number">
          Area do CAR em hectares.
        </ResponseField>

        <ResponseField name="modulos_fiscais" type="number">
          Quantidade de modulos fiscais.
        </ResponseField>

        <ResponseField name="status" type="string">
          Status do CAR: `AT` (Ativo), `PE` (Pendente), `CA` (Cancelado), `SU` (Suspenso).
        </ResponseField>

        <ResponseField name="tipo" type="string">
          Tipo do imovel: `IRU` (Imovel Rural), `AST` (Assentamento), `PCT` (Territorio Tradicional).
        </ResponseField>

        <ResponseField name="condicao" type="string">
          Condicao de analise (ex: `Aguardando analise`, `Analisado`).
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<RequestExample>
```bash cURL
curl -X GET "https://data.dadosfazenda.com.br/imovel/433133781" \
  -H "Authorization: Bearer SEU_TOKEN_API"
```

```python Python
import httpx

response = httpx.get(
    "https://data.dadosfazenda.com.br/imovel/433133781",
    headers={"Authorization": "Bearer SEU_TOKEN"}
)
data = response.json()

print(f"Imovel: {data['data']['denominacao']}")
print(f"Titulares: {len(data['data']['titulares'])}")
for t in data["data"]["titulares"]:
    print(f"  {t['nome']} ({t['percentual']}%)")
```
</RequestExample>
