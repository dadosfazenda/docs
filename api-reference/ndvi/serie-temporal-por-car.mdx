---

## Descricao

Retorna a serie temporal dos indices de vegetacao **NDVI** e **NDRE** para uma propriedade rural a partir do codigo CAR.

- **NDVI** (Normalized Difference Vegetation Index): calculado com bandas NIR (B08) e Red (B04). Indica vigor da vegetacao.
- **NDRE** (Normalized Difference Red Edge): calculado com bandas NIR (B08) e Red Edge (B05). Mais sensivel a variacao de clorofila e estagio fenologico.

Ambos os indices sao calculados a partir de imagens do satelite **Sentinel-2** com resolucao de **10 metros**.

**Periodo maximo permitido: 90 dias.**

Quando `images=true`, inclui URLs assinadas para imagens RGB, NDVI e NDRE processadas (validade de 1 hora).

Fonte: Sentinel-2 L2A via Planetary Computer (Microsoft). Resolucao: 10m. Mascaramento de nuvens automatico (banda SCL).

<ParamField path="codigo_car" type="string" required>
  Codigo do CAR. Exemplo: `MT-5106505-EC68A6B4C2AF4EB283BCE84BF6D56A17`
</ParamField>

<ParamField query="start_date" type="string">
  Data inicio no formato `YYYY-MM-DD`. Default: 90 dias atras.
</ParamField>

<ParamField query="end_date" type="string">
  Data fim no formato `YYYY-MM-DD`. Default: hoje. Maximo de 90 dias de intervalo.
</ParamField>

<ParamField query="images" type="boolean" default={false}>
  Se `true`, gera imagens de satelite (RGB, NDVI e NDRE) e retorna URLs assinadas com validade de 1 hora.
</ParamField>

<ParamField query="force" type="boolean" default={false}>
  Se `true`, recalcula os indices mesmo se houver dados em cache.
</ParamField>

### Escala NDVI

| Faixa | Classificacao |
|-------|--------------|
| -1.0 a 0.0 | Agua, nuvens, areas urbanas (`water_clouds_urban`) |
| 0.0 a 0.1 | Solo exposto / areas urbanas (`bare_soil_urban`) |
| 0.1 a 0.2 | Solo exposto (`bare_soil`) |
| 0.2 a 0.5 | Vegetacao esparsa (`sparse_vegetation`) |
| 0.5 a 1.0 | Vegetacao densa e saudavel (`dense_healthy_vegetation`) |

### Escala NDRE

| Faixa | Classificacao |
|-------|--------------|
| -1.0 a 0.0 | Agua / areas nao vegetadas (`water_non_vegetated`) |
| 0.0 a 0.1 | Solo exposto (`bare_soil`) |
| 0.1 a 0.2 | Vegetacao inicial / esparsa (`early_sparse_vegetation`) |
| 0.2 a 0.4 | Vegetacao moderada (`moderate_vegetation`) |
| 0.4 a 0.6 | Vegetacao densa e saudavel (`dense_healthy_vegetation`) |
| 0.6 a 1.0 | Vegetacao muito densa (`very_dense_healthy_vegetation`) |

<Note>
  O NDRE e mais sensivel a diferencas de clorofila que o NDVI. Enquanto o NDVI satura em areas de vegetacao muito densa, o NDRE continua diferenciando niveis de saude da planta. Use o NDRE para monitoramento de lavouras e deteccao precoce de estresse.
</Note>

```python Python
import httpx

response = httpx.get(
    "https://data-api.dadosfazenda.com.br/ndvi/car/MT-5106505-EC68A6B4C2AF4EB283BCE84BF6D56A17/timeseries",
    params={
        "start_date": "2025-01-01",
        "end_date": "2025-03-01",
        "images": True,
    },
    headers={"Authorization": "Bearer SEU_TOKEN"}
)
data = response.json()["data"]
for point in data["timeseries"]:
    ndre = point.get("ndre_mean", "N/A")
    print(f"{point['scene_date']}: NDVI={point['ndvi_mean']:.3f}, NDRE={ndre}")
```
