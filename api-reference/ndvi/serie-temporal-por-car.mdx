---

## Descricao

Retorna a serie temporal do indice de vegetacao **NDVI** (Normalized Difference Vegetation Index) para uma propriedade rural a partir do codigo CAR.

O NDVI e calculado a partir de imagens de satelite com resolucao de **10 metros**, usando as bandas NIR e Red.

**Periodo maximo permitido: 90 dias.**

<ParamField path="codigo_car" type="string" required>
  Codigo do CAR. Exemplo: `MT-5106505-B2C3D4E5F60718293A4B5C6D7E8F90A1`
</ParamField>

<ParamField query="start_date" type="string">
  Data inicio no formato `YYYY-MM-DD`. Default: 90 dias atras.
</ParamField>

<ParamField query="end_date" type="string">
  Data fim no formato `YYYY-MM-DD`. Default: hoje. Maximo de 90 dias de intervalo.
</ParamField>

### Escala NDVI

| Faixa | Classificacao |
|-------|--------------|
| -1.0 a 0.0 | Agua, nuvens, areas urbanas |
| 0.0 a 0.1 | Solo exposto / areas urbanas |
| 0.1 a 0.2 | Solo exposto |
| 0.2 a 0.5 | Vegetacao esparsa |
| 0.5 a 1.0 | Vegetacao densa e saudavel |

<RequestExample>
```bash cURL
curl -X GET "https://data.dadosfazenda.com.br/ndvi/car/MT-5106505-B2C3D4E5F60718293A4B5C6D7E8F90A1/timeseries?start_date=2025-01-01&end_date=2025-03-01" \
  -H "Authorization: Bearer SEU_TOKEN_API"
```

```python Python
import httpx

response = httpx.get(
    "https://data.dadosfazenda.com.br/ndvi/car/MT-5106505-B2C3D4E5F60718293A4B5C6D7E8F90A1/timeseries",
    params={
        "start_date": "2025-01-01",
        "end_date": "2025-03-01",
    },
    headers={"Authorization": "Bearer SEU_TOKEN"}
)
data = response.json()["data"]
for point in data["timeseries"]:
    print(f"{point['scene_date']}: NDVI={point['ndvi_mean']:.3f}")
```
