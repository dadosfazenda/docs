## Descrição

Consulta ao Cadastro Nacional de Condenações Cíveis por Ato de Improbidade Administrativa (CNJ).

A consulta é **síncrona**: a API processa e retorna os dados estruturados e,
quando houver, os arquivos oficiais (PDF) com **URL de download assinada
(validade de 30 minutos)**.

## Autenticação

Envie sua API key no header `Authorization: Bearer SEU_TOKEN`. Cada chamada
bem-sucedida consome **1 unidade** da cota mensal. Em erro de consulta a cota
é estornada.

## Parâmetros

<ParamField body="cpf" type="string" required>
  CPF do titular (apenas dígitos, 11 caracteres).
</ParamField>

<ParamField body="nome_completo" type="string" required>
  Nome completo do titular.
</ParamField>

## Resposta

<ResponseField name="certidao" type="string">
  Identificador da certidão consultada (`cnj_improbidade`).
</ResponseField>

<ResponseField name="data" type="object">
  Payload estruturado do resultado (varia conforme a certidão).
</ResponseField>

<ResponseField name="arquivos" type="array">
  Lista de arquivos oficiais. Cada item traz `filename`, `content_type`,
  `kind`, `url` (assinada) e `expires_in` (segundos até expirar - 1800 = 30 min).
</ResponseField>

<RequestExample>

```bash cURL
curl -X POST "https://data.dadosfazenda.com.br/v1/certidoes/cnj_improbidade" \
  -H "Authorization: Bearer SEU_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "cpf": "12345678909",
    "nome_completo": "João da Silva"
  }'
```

</RequestExample>

<ResponseExample>

```json 200 OK
{
  "success": true,
  "message": "Success",
  "data": {
    "certidao": "cnj_improbidade",
    "data": { },
    "arquivos": [
      {
        "filename": "cnj_improbidade.pdf",
        "content_type": "application/pdf",
        "kind": "official_pdf",
        "url": "https://data.dadosfazenda.com.br/storage/v1/object/sign/certidoes/...",
        "expires_in": 1800
      }
    ]
  }
}
```

```json 401 - API key inválida
{ "detail": "API key invalida." }
```

```json 429 - cota mensal atingida
{ "detail": "Limite mensal atingido. Reseta no proximo mes." }
```

</ResponseExample>
