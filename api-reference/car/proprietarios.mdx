---
title: "Proprietários do CAR"
api: "GET /car/{codigo_car}/proprietarios"
description: "Retorna os proprietários de um imóvel rural identificado pelo código CAR, com dados pessoais enriquecidos."
---

## Descricao

Consulta os proprietários vinculados a um CAR com enriquecimento de dados pessoais (telefones, emails, idade, etc).

Quando disponíveis, os dados do imóvel (denominação, matrícula, cartório) são retornados dentro de `dados_car`.

<ParamField path="codigo_car" type="string" required>
  Código do CAR. Exemplo: `GO-5211909-8D9398BED77F4EC88CB75EED7FB0FC42`
</ParamField>


## Response

<ResponseField name="data" type="object">
  <Expandable title="data">
    <ResponseField name="dados_car" type="object">
      Dados do CAR. Quando disponível, inclui também informações do imóvel (matrícula, cartório, denominação).

      <Expandable title="dados_car">
        <ResponseField name="codigo" type="string">Código do CAR.</ResponseField>
        <ResponseField name="municipio" type="string">Município.</ResponseField>
        <ResponseField name="estado" type="string">UF.</ResponseField>
        <ResponseField name="area_ha" type="number">Área em hectares.</ResponseField>
        <ResponseField name="status" type="string">Status: `AT`, `PE`, `CA`, `SU`.</ResponseField>
        <ResponseField name="tipo" type="string">Tipo: `IRU`, `AST`.</ResponseField>
        <ResponseField name="denominacao" type="string">Nome do imóvel (quando disponível).</ResponseField>
        <ResponseField name="matricula" type="string">Número da matrícula no cartório (quando disponível).</ResponseField>
        <ResponseField name="data_matricula" type="string">Data da matrícula (quando disponível).</ResponseField>
        <ResponseField name="cartorio" type="string">Cartório de registro (quando disponível).</ResponseField>
        <ResponseField name="tipo_imovel" type="string">Tipo do imóvel, ex: `Imóvel Rural` (quando disponível).</ResponseField>
        <ResponseField name="uf" type="string">UF do imóvel (quando disponível).</ResponseField>
        <ResponseField name="codigo_protocolo" type="string">Código de protocolo do imóvel (quando disponível).</ResponseField>
      </Expandable>
    </ResponseField>

    <ResponseField name="dados_titulares" type="array">
      Lista de proprietários encontrados. Vazia se nenhuma fonte retornar resultado.

      <Expandable title="dados_titulares[]">
        <ResponseField name="nome" type="string">Nome do proprietário conforme fonte original.</ResponseField>
        <ResponseField name="cpf_cnpj" type="string">CPF ou CNPJ formatado (ex: `841.897.381-15`).</ResponseField>
        <ResponseField name="cpf" type="string">CPF sem formatação (ex: `84189738115`).</ResponseField>
        <ResponseField name="cpf_formato" type="string">CPF formatado.</ResponseField>
        <ResponseField name="sexo" type="string">`MASCULINO` ou `FEMININO`.</ResponseField>
        <ResponseField name="data_nascimento" type="string">Data de nascimento.</ResponseField>
        <ResponseField name="idade" type="number">Idade atual.</ResponseField>
        <ResponseField name="emails" type="array">Lista de emails encontrados (strings).</ResponseField>
        <ResponseField name="telefones" type="array">
          Lista de telefones.

          <Expandable title="telefones[]">
            <ResponseField name="ddd" type="string">DDD.</ResponseField>
            <ResponseField name="telefone" type="string">Número sem DDD.</ResponseField>
            <ResponseField name="tipo" type="string">Ex: `TELEFONE MÓVEL`, `TELEFONE RESIDENCIAL`.</ResponseField>
            <ResponseField name="operadora" type="string">Operadora (pode ser vazio).</ResponseField>
          </Expandable>
        </ResponseField>
      </Expandable>
    </ResponseField>

    <ResponseField name="ccir" type="string">
      Código CCIR (código do imóvel INCRA). Presente apenas quando há match com SIGEF.
    </ResponseField>

    <ResponseField name="sobreposicao" type="object">
      Métricas de sobreposição CAR/SIGEF.

      <Expandable title="sobreposicao">
        <ResponseField name="percentual_car_coberto" type="number">Percentual do CAR coberto por SIGEF.</ResponseField>
      </Expandable>
    </ResponseField>

    <ResponseField name="cache" type="boolean">
      `true` se os dados geométricos vieram do cache local.
    </ResponseField>
  </Expandable>
</ResponseField>

<RequestExample>
```bash cURL
curl -X GET "https://data.dadosfazenda.com.br/car/GO-5211909-8D9398BED77F4EC88CB75EED7FB0FC42/proprietarios" \
  -H "Authorization: Bearer SEU_TOKEN_API"
```

```python Python
import httpx

response = httpx.get(
    "https://data.dadosfazenda.com.br/car/GO-5211909-8D9398BED77F4EC88CB75EED7FB0FC42/proprietarios",
    headers={"Authorization": "Bearer SEU_TOKEN_API"}
)
data = response.json()["data"]

print(f"Imóvel: {data['dados_car'].get('denominacao', '-')}")
print(f"Matrícula: {data['dados_car'].get('matricula', '-')}")

for t in data["dados_titulares"]:
    print(f"{t['nome']} - CPF: {t['cpf_cnpj']}")
    for tel in t.get("telefones", []):
        print(f"  ({tel['ddd']}) {tel['telefone']} - {tel['tipo']}")
```
</RequestExample>
