---
title: "CARs por Cultura"
api: "GET /sicor/cars-por-cultura"
description: "Busca CARs que possuem operacoes de credito rural para uma cultura especifica, com historico ano a ano"
---

## Descricao

Retorna todos os CARs que possuem operacoes de credito rural vinculadas a uma cultura especifica (ex: SOJA, MILHO, CAFE).

Para cada CAR, retorna um historico ano a ano com valor financiado, area e finalidade do credito.

<ParamField query="produto" type="string" required>
  Nome da cultura/produto. Exemplo: `SOJA`, `MILHO`, `CAFE`, `ALGODAO`
</ParamField>

<ParamField query="uf" type="string">
  Filtro por estado. Exemplo: `MT`, `GO`, `BA`
</ParamField>

<ParamField query="year_min" type="integer">
  Ano minimo. Exemplo: `2016`
</ParamField>

<ParamField query="year_max" type="integer">
  Ano maximo. Exemplo: `2025`
</ParamField>

<ParamField query="offset" type="integer" default="0">
  Offset para paginacao.
</ParamField>

<ParamField query="limit" type="integer" default="50">
  Quantidade por pagina.
</ParamField>

## Response

    <ResponseField name="produto" type="string">

        <ResponseField name="ultimo_ano" type="integer">Ultimo ano com operacao.</ResponseField>
        <ResponseField name="valor_total" type="number">Valor total financiado (R$).</ResponseField>
        <ResponseField name="area_total_ha" type="number">Area total financiada (hectares).</ResponseField>

          <Expandable title="registro">
            <ResponseField name="ano" type="integer">Ano da operacao.</ResponseField>

            <ResponseField name="valor_credito" type="number">Valor financiado no ano (R$).</ResponseField>
            <ResponseField name="area_financiada_ha" type="number">Area financiada no ano (hectares).</ResponseField>

      </Expandable>
    </ResponseField>

    <ResponseField name="metadata" type="object">
      Metadados de paginacao.
    </ResponseField>
  </Expandable>
</ResponseField>

<RequestExample>
```bash cURL
curl -X GET "https://data.dadosfazenda.com.br/sicor/cars-por-cultura?produto=SOJA&uf=MT&year_min=2016" \
  -H "Authorization: Bearer SEU_TOKEN_API"
```

```python Python
import httpx

response = httpx.get(
    "https://data.dadosfazenda.com.br/sicor/cars-por-cultura",
    params={"produto": "SOJA", "uf": "MT", "year_min": 2016},
    headers={"Authorization": "Bearer SEU_TOKEN_API"}
)
data = response.json()["data"]
print(f"Total de CARs com SOJA: {data['total']}")

for car in data["cars"]:
    print(f"\n{car['codigo_car']} - {car['uf']} - {car['anos_com_credito']} anos")
    for h in car["historico"]:
        print(f"  {h['ano']}: {h['finalidade']} - R$ {h['valor_credito']:,.2f} - {h['area_financiada_ha']} ha")
```
</RequestExample>
