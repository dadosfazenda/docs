---
title: "Busca por CPF/CNPJ"
api: "GET /cpf-car/{cpf_cnpj}"
description: "Busca propriedades rurais (CAR) vinculadas a um CPF ou CNPJ"
---

## Descricao

A partir de um CPF ou CNPJ, esta rota identifica todos os imoveis rurais vinculados ao documento e tenta vincular cada um ao respectivo CAR (Cadastro Ambiental Rural).

A resposta retorna dados basicos de cada imovel, o CAR vinculado quando encontrado, e o **registro CAFIR** (Receita Federal) com NIRF, situacao fiscal e flag de imune/isento. Para dados detalhados de um imovel (titulares, cartorio, CCIR), utilize a rota [Detalhes do imovel](/api-reference/detalhes-imovel).

<ParamField path="cpf_cnpj" type="string" required>
  CPF (11 digitos) ou CNPJ (14 digitos). Aceita com ou sem formatacao (pontos, tracos, barras).

  Exemplos: `12345678901`, `123.456.789-01`, `12345678000199`
</ParamField>

## Response

<ResponseField name="message" type="string">
  Mensagem descritiva do resultado.
</ResponseField>

<ResponseField name="data" type="object">
  <Expandable title="data">
    <ResponseField name="cpf_cnpj" type="string">
      Documento consultado (somente digitos).
    </ResponseField>

    <ResponseField name="total_imoveis" type="integer">
      Total de imoveis rurais encontrados para este documento.
    </ResponseField>

    <ResponseField name="cars_encontrados" type="integer">
      Total de CARs que foram vinculados com sucesso.
    </ResponseField>

    <ResponseField name="propriedades" type="array">
      Lista de propriedades encontradas.

      <Expandable title="propriedade">
        <ResponseField name="codigo_imovel" type="string">
          Codigo do imovel (ex: `433133781`).
        </ResponseField>

        <ResponseField name="denominacao" type="string">
          Nome do imovel (ex: `Fazenda Esperanca`).
        </ResponseField>

        <ResponseField name="municipio" type="string">
          Municipio do imovel.
        </ResponseField>

        <ResponseField name="uf" type="string">
          UF do imovel (ex: `GO`).
        </ResponseField>

        <ResponseField name="area_total_ha" type="number">
          Area total do imovel em hectares.
        </ResponseField>

        <ResponseField name="cafir" type="object">
          Dados do registro CAFIR (Cadastro de Imoveis Rurais da Receita Federal). `null` se nao houver vinculacao do imovel ao CAFIR.

          <Expandable title="cafir">
            <ResponseField name="nirf" type="string">
              NIRF — Numero do imovel na Receita Federal (8 caracteres alfanumericos).
            </ResponseField>
            <ResponseField name="nome" type="string">
              Nome do imovel registrado na RF.
            </ResponseField>
            <ResponseField name="area_ha" type="number">
              Area do imovel declarada na RF, em hectares.
            </ResponseField>
            <ResponseField name="uf" type="string">
              UF do imovel.
            </ResponseField>
            <ResponseField name="municipio" type="string">
              Municipio do imovel.
            </ResponseField>
            <ResponseField name="cep" type="string">
              CEP do imovel.
            </ResponseField>
            <ResponseField name="situacao" type="string">
              Situacao fiscal do imovel — valores possiveis: `ativo`, `cancelado_*` (12 motivos), `pendencia_*` (7 motivos).
            </ResponseField>
            <ResponseField name="situacao_codigo" type="integer">
              Codigo numerico da situacao (2=ativo, 46-59=cancelamentos, 83-98=pendencias). Ver [docs/CAFIR.md](https://github.com/dadosfazenda/dadosfazenda-data-api/blob/main/docs/CAFIR.md).
            </ResponseField>
            <ResponseField name="imune_isento" type="boolean">
              `true` se o imovel e imune ou isento de ITR (igrejas, escolas, fundacoes sem fins lucrativos).
            </ResponseField>
            <ResponseField name="sncr_status" type="string">
              Status da vinculacao com o INCRA — valores possiveis: `vinculacao_provisoria`, `vinculacao_confirmada`, `desvinculado`, `descaracterizacao_rural`.
            </ResponseField>
            <ResponseField name="sncr_codigo" type="integer">
              Codigo numerico do status SNCR (1-4).
            </ResponseField>
            <ResponseField name="data_atualizacao" type="string">
              Data da ultima atualizacao do registro na RF (ISO 8601, AAAA-MM-DD).
            </ResponseField>
            <ResponseField name="data_snapshot" type="string">
              Data da extracao oficial da RF de onde este registro veio (ISO 8601, AAAA-MM-DD).
            </ResponseField>
          </Expandable>
        </ResponseField>

        <ResponseField name="car" type="object">
          Dados do CAR vinculado. `null` se nenhum CAR foi encontrado.

          <Expandable title="car">
            <ResponseField name="codigo" type="string">
              Codigo do CAR (ex: `GO-5203401-617CD0C0367A49CD809862F382945511`).
            </ResponseField>

            <ResponseField name="municipio" type="string">
              Municipio do CAR.
            </ResponseField>

            <ResponseField name="estado" type="string">
              UF do CAR (ex: `GO`).
            </ResponseField>

            <ResponseField name="area_ha" type="number">
              Area do CAR em hectares.
            </ResponseField>

            <ResponseField name="modulos_fiscais" type="number">
              Quantidade de modulos fiscais.
            </ResponseField>

            <ResponseField name="status" type="string">
              Status do CAR: `AT` (Ativo), `PE` (Pendente), `CA` (Cancelado), `SU` (Suspenso).
            </ResponseField>

            <ResponseField name="tipo" type="string">
              Tipo do imovel: `IRU` (Imovel Rural), `AST` (Assentamento), `PCT` (Territorio Tradicional).
            </ResponseField>

            <ResponseField name="condicao" type="string">
              Condicao de analise (ex: `Aguardando analise`, `Analisado`).
            </ResponseField>
          </Expandable>
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>

<RequestExample>
```bash cURL
curl -X GET "https://data.dadosfazenda.com.br/cpf-car/12345678901" \
  -H "Authorization: Bearer SEU_TOKEN_API"
```

```python Python
import httpx

response = httpx.get(
    "https://data.dadosfazenda.com.br/cpf-car/12345678901",
    headers={"Authorization": "Bearer SEU_TOKEN"}
)
data = response.json()

for prop in data["data"]["propriedades"]:
    print(f"{prop['denominacao']} - {prop['municipio']}/{prop['uf']}")
    if prop["car"]:
        print(f"  CAR: {prop['car']['codigo']}")
```
</RequestExample>
