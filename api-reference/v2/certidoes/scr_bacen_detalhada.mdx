## Descrição

Posição detalhada do SCR (Sistema de Informações de Créditos) do Banco
Central por CPF ou CNPJ: responsabilidade total, score e faixa de risco,
carteira de crédito (limite, a vencer, vencido, prejuízo) e a abertura das
operações por modalidade, com aging de vencimentos. O SCR consolida as
operações de crédito reportadas mensalmente pelas instituições financeiras.

A consulta é **síncrona**: a API processa e retorna os dados estruturados e,
quando houver, os arquivos oficiais (PDF) com **URL de download assinada
(validade de 30 minutos)**.

## Autenticação

Envie sua API key no header `Authorization: Bearer SEU_TOKEN`. Cada chamada
bem-sucedida consome **1 unidade** da cota mensal. Em erro de consulta a cota
é estornada.

## Parâmetros

<ParamField body="cpf_cnpj" type="string" required>
  CPF ou CNPJ do titular (apenas dígitos).
</ParamField>

<ParamField body="mesano" type="string">
  Competência (MMyyyy, ex.: `062026`). Informada, retorna o SCR daquele mês;
  omitida, retorna a competência mais recente disponível.
</ParamField>
