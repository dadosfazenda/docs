---
title: "Consumo da API"
description: "Consulte cota, saldo, requisições e valores cobrados com a própria API key"
api: "GET /v2/account/usage"
---

Retorna o consumo do contrato ao qual a API key pertence. A consulta é
gratuita: não consome franquia, não debita saldo e não aparece no próprio
histórico.

Por padrão, a janela consultada começa no primeiro dia do mês corrente e
termina no dia atual, considerando o fuso `America/Sao_Paulo`.

```bash
curl "https://data.dadosfazenda.com.br/v2/account/usage" \
  -H "Authorization: Bearer $API_KEY"
```

## Filtros

| Parâmetro | Tipo | Padrão | Descrição |
| --- | --- | --- | --- |
| `start_date` | `date` | primeiro dia do mês | Início inclusivo no formato `YYYY-MM-DD`. |
| `end_date` | `date` | hoje | Fim inclusivo no formato `YYYY-MM-DD`. |
| `status` | `string` | todos | `success` ou `error`. |
| `endpoint` | `string` | todos | Caminho exato do endpoint. |
| `limit` | `integer` | `50` | De 1 a 200 requisições por página. |
| `offset` | `integer` | `0` | Deslocamento da paginação. |

A janela máxima é de 366 dias. Não existe parâmetro de contrato: o escopo é
derivado da chave autenticada, impedindo a leitura do consumo de terceiros.
