---

## Descrição

Cadastro completo do CNPJ com estimativa de faturamento: faixa de
faturamento, faturamento presumido, faturamento médio do CNAE, porte,
natureza jurídica, CNAEs principal e secundários, regime tributário,
quadro societário, filiais, endereços, telefones e e-mails.

Esta rota retorna apenas os dados estruturados, sem comprovante.

<ParamField path="cnpj" type="string" required>
  CNPJ (14 dígitos), com ou sem formatação
</ParamField>
