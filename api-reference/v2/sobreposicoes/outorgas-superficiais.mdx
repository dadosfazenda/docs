---

## Descrição

Outorgas de captação superficial de água (ANA) dentro do imóvel. Informe o código do CAR: a resposta diz se há ocorrência, traz cada uma com seus atributos e o polígono em GeoJSON.

Para saber apenas SE existe ocorrência (sem os detalhes), use o [resumo de sobreposições](/api-reference/v2/sobreposicoes-resumo), que responde todas as camadas de uma vez.

<ParamField path="codigo_car" type="string" required>
  Código do CAR. Exemplo: `GO-5211909-40A31261C76845DCBE6C47797F9B7B57`
</ParamField>

<ParamField query="geometria" type="boolean" default="true">
  Incluir o polígono de cada ocorrência. Com `false`, a resposta fica muito menor em camadas densas.
</ParamField>

<ParamField query="limite" type="integer" default="200">
  Máximo de ocorrências (1 a 1000). Ao atingir o limite, a resposta traz `truncado: true`.
</ParamField>
