# DadosFazenda Data API

Consulte dados de qualquer propriedade rural do Brasil de forma unificada:
cadastro e titularidade, situação ambiental, clima, solo, uso da terra e
crédito, com os cruzamentos já resolvidos.

As consultas ficam na aba **API Reference**, organizadas por grupos.

## Base URL

```
https://data.dadosfazenda.com.br
```

Todas as rotas documentadas usam o prefixo `/v2`.

## Autenticação

Envie sua API key no header de toda requisição:

```bash
curl "https://data.dadosfazenda.com.br/v2/cpf-car/12345678909" \
  -H "Authorization: Bearer SUA_API_KEY"
```

Cada chamada bem-sucedida consome 1 unidade da cota mensal da sua chave.
Em caso de erro na consulta, a cota é estornada.

## Formato de resposta

```json Sucesso
{
  "success": true,
  "message": "Descricao do resultado",
  "data": { ... }
}
```

```json Erro
{
  "success": false,
  "message": "Descricao do erro",
  "data": null
}
```

| Codigo | Significado |
|--------|-------------|
| `400` | Parametros invalidos |
| `401` | Token ausente ou invalido |
| `403` | API key desativada |
| `404` | Recurso nao encontrado |
| `429` | Limite mensal de requests atingido |
| `502` | Erro em API externa |
